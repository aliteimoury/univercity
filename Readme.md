#### University Attendance System

#### پروژه مدیریت حضور و غیاب دانشگاه با استفاده از HTML، CSS، PHP و MySQL روی XAMPP توسعه داده شده است.

#### این سیستم شامل احراز هویت، مدیریت نقش‌ها، نمایش کلاس‌ها و ثبت حضور است.

#### در ادامه گزارش کامل ۴ جلسه توسعه پروژه آورده شده است.

#### جلسه ۱: تحلیل و طراحی اولیه پروژه

#### در این مرحله تمرکز اصلی روی شناخت کامل نیازمندی‌ها و طراحی زیرساخت پروژه بود.

#### توضیحات تکمیلی:

#### •	ابتدا تمامی نیازهای سیستم حضور و غیاب بررسی شد، مانند: مدیریت کاربران، نقش‌ها، کلاس‌ها و ثبت حضور.

#### •	مدل پایگاه داده به صورت ERD طراحی شد تا ساختار ارتباطی بین جداول کاملاً مشخص باشد. جداول اصلی شامل:

#### o	Users: مشخصات و نقش کاربران

#### o	Classes: اطلاعات کلاس‌ها

#### o	Attendance: وضعیت حضور کاربران در کلاس‌ها

#### •	تکنولوژی‌ها بر اساس سادگی، سرعت اجرا و مناسب بودن برای پروژه انتخاب شدند:

#### o	Frontend: HTML و CSS برای بخش نمایشی

#### o	Backend: PHP برای پردازش داده‌ها

#### o	Database: MySQL برای ذخیره‌سازی اطلاعات

#### •	محیط توسعه روی XAMPP راه‌اندازی شد تا Apache و MySQL به‌صورت محلی اجرا شوند.

#### •	مخزن Git ساخته شد تا روند توسعه پروژه مرحله‌به‌مرحله قابل پیگیری باشد.

#### تحویل‌دادنی‌های جلسه ۱:

#### •	طراحی ERD کامل پروژه

#### •	توضیح نیازمندی‌ها و معماری اولیه

#### •	ایجاد مخزن Git و شروع ساختار پروژه

#### جلسه ۲: پیاده‌سازی پایگاه داده و ساختار اولیه پروژه

#### در این جلسه بخش پایه‌ای و فنی پروژه پیاده‌سازی شد و ساختار اصلی پروژه شکل گرفت.

#### توضیحات تکمیلی:

#### •	دیتابیس پروژه در phpMyAdmin ساخته شد و جداول اصلی مطابق ERD ایجاد شدند:

#### o	جدول Users شامل فیلدهای نام، ایمیل، رمز عبور و نقش

#### o	جدول Classes شامل اطلاعات کلاس

#### o	جدول Attendance برای ذخیره سوابق حضور

#### •	اتصال PHP به MySQL پیاده‌سازی شد و فایل کانفیگ دیتابیس نوشته شد.

#### •	پوشه‌بندی پروژه مشخص شد (مثل pages، auth، includes و ...).

#### •	یک صفحه ساده HTML/CSS ساخته شد تا ساختار ظاهری پروژه شکل بگیرد و برای توسعه صفحات بعدی آماده باشد.

#### تحویل‌دادنی‌های جلسه ۲:

#### •	دیتابیس و تمامی جداول اصلی

#### •	فایل اتصال PHP به دیتابیس

#### •	صفحه اولیه پروژه با HTML/CSS

#### جلسه ۳: پیاده‌سازی سیستم ثبت‌نام و ورود کاربران (Authentication)

#### این جلسه یکی از مهم‌ترین بخش‌های پروژه بود؛ جایی که سیستم احراز هویت کامل ساخته شد.

#### توضیحات تکمیلی:

#### •	فرم ثبت‌نام و ورود با HTML و CSS ساخته شد.

#### •	بخش پردازش فرم‌ها به‌صورت کامل با PHP انجام شد:

#### o	ثبت‌نام: دریافت اطلاعات کاربر و ذخیره آن در دیتابیس

#### o	هش کردن رمز عبور با password\_hash() برای امنیت

#### o	ورود: بررسی اطلاعات ورودی و تطبیق رمز عبور با password\_verify()

#### •	برای مدیریت ورود کاربران، از Session استفاده شد تا وضعیت کاربر بعد از ورود حفظ شود.

#### •	کنترل خطا در هر دو فرم انجام شد، مثل:

#### o	خالی بودن ورودی‌ها

#### o	ایمیل تکراری

#### o	رمز اشتباه

#### تحویل‌دادنی‌های جلسه ۳:

#### •	فرم‌های Sign Up و Login

#### •	فایل‌های PHP برای پردازش ثبت‌نام و ورود

#### •	مدیریت کامل Session

#### جلسه ۴: پیاده‌سازی نقش‌ها و داشبورد کاربران

#### در این مرحله پروژه از حالت ساده خارج شد و براساس نقش کاربران عملکرد متفاوت ایجاد شد.

#### توضیحات تکمیلی:

#### •	دو نقش اصلی ایجاد شد:

#### o	Student (دانشجو)

#### o	Teacher (مدرس)

#### •	کنترل سطح دسترسی پیاده‌سازی شد تا هر نقش فقط به صفحات مخصوص خودش دسترسی داشته باشد.

#### •	داشبورد دانشجو شامل:

#### o	نمایش لیست کلاس‌هایی که دانشجو در آنها ثبت‌نام شده

#### •	داشبورد مدرس شامل:

#### o	نمایش لیست کلاس‌هایی که مدرس ایجاد کرده

#### •	سیستم Logout پیاده‌سازی شد که Session کاربر را حذف می‌کند و او را به صفحه ورود بازمی‌گرداند.

#### •	تست‌های مختلف انجام شد تا اطمینان حاصل شود یک نقش نمی‌تواند وارد صفحات نقش دیگر شود.

#### تحویل‌دادنی‌های جلسه ۴:

#### •	داشبورد مخصوص هر نقش

#### •	کنترل سطح دسترسی برای صفحات

#### •	پیاده‌سازی سیستم Logout

#### •	نقش‌بندی کامل در پروژه

#### جلسه ۵: پیاده‌سازی مدیریت کلاس‌ها

#### در این جلسه تمرکز روی ایجاد امکان مدیریت کلاس‌ها توسط مدرس بود.

#### توضیحات تکمیلی:

#### •	فرم Frontend برای ایجاد کلاس طراحی شد که شامل فیلدهای زیر بود:

#### o	نام کلاس

#### o	زمان برگزاری

#### o	توضیحات تکمیلی

#### •	APIهای PHP برای مدیریت کلاس‌ها ایجاد شد:

#### o	/create-class برای ایجاد کلاس جدید

#### o	/classes برای نمایش لیست کلاس‌ها

#### •	دانشجویان می‌توانند در کلاس‌ها ثبت‌نام کنند، این کار از طریق فرم یا دکمه ثبت‌نام در لیست کلاس‌ها انجام شد.

#### •	کنترل دسترسی اعمال شد تا فقط نقش مدرس بتواند کلاس جدید ایجاد کند و دانشجو فقط قادر به مشاهده و ثبت‌نام باشد.

#### تحویل‌دادنی‌های جلسه ۵:

#### •	فرم ایجاد کلاس و لیست کلاس‌ها در Frontend

#### •	فایل‌های PHP مربوط به API مدیریت کلاس‌ها

#### •	تست عملکرد ایجاد کلاس و ثبت‌نام دانشجو

#### جلسه ۶: پیاده‌سازی ثبت حضور

#### هدف این جلسه افزودن قابلیت ثبت حضور برای دانشجو و مدیریت آن توسط مدرس بود.

#### توضیحات تکمیلی:

#### •	رابط کاربری Frontend برای ثبت حضور طراحی شد.

#### o	دانشجو می‌تواند با دکمه «حاضر» وضعیت حضور خود را ثبت کند.

#### •	APIهای PHP ایجاد شدند:

#### o	/attend برای ثبت حضور با ذخیره تاریخ و زمان

#### o	ویرایش وضعیت حضور توسط مدرس (مثلاً تغییر از حاضر به غایب یا بالعکس)

#### •	کنترل دسترسی اعمال شد تا دانشجو فقط بتواند حضور خودش را ثبت کند و مدرس بتواند وضعیت همه دانشجویان کلاس خود را ویرایش کند.

#### •	تمامی امکانات به صورت دستی تست شدند تا صحت عملکرد ثبت و ویرایش حضور تضمین شود.

#### تحویل‌دادنی‌های جلسه ۶:

#### •	رابط کاربری ثبت حضور در Frontend

#### •	APIهای PHP برای ثبت و ویرایش حضور

#### •	تست عملکرد سیستم حضور
